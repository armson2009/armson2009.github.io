Comment ça marche

Quatre étapes, directement depuis votre téléphone.

  1. Connectez-vous au Wi-Fi « Saioua Connecté » depuis votre appareil.
  2. La page d'achat s'ouvre : choisissez votre forfait.
  3. Payez par Mobile Money (Orange Money, MTN MoMo ou Wave).
  4. Votre code s'affiche à l'écran : connectez-vous et profitez d'internet.

Nos services

Saioua Connecté apporte internet là où la connexion manquait.

Wi-Fi par tickets

Un code valable 1 jour, 3 jours, 1 semaine ou 1 mois pour vous connecter au réseau public de Saioua.

Wi-Fi à la maison

Un abonnement mensuel pour avoir internet chez vous, grâce à une antenne longue portée installée par nos soins.

Hôtels et commerces

Un réseau Wi-Fi avec votre propre page de connexion et des forfaits adaptés à vos clients.

Paiement et assistance

Payer doit rester simple et rassurant.

Paiement sécurisé

Le paiement se fait sur la page de nos partenaires de paiement agréés. Nous ne voyons jamais votre code secret Mobile Money.

Code immédiat

Dès que le paiement est confirmé, votre code s'affiche à l'écran et vous pouvez vous connecter.

Un souci ?

Si vous avez payé sans recevoir de code, contactez-nous avec le numéro utilisé et l'heure du paiement. Après vérification, nous vous renvoyons votre code ou nous vous remboursons.
